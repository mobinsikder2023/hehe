# Science Bee One-Link Studio V10

One news URL → humanized Bengali headline + supporting line + 10–15 sentence caption + image candidates + editable 4:5 poster + persistent PNG + share link.

The package is based on the working Science Bee prototype supplied by the owner. The existing poster design values were preserved conceptually while moving the production renderer to a Vercel-friendly Node pipeline.

See `VERCEL_DEPLOY.md` for the complete setup.
